Vidspace - Your Personal Video Hub!

I've created this web app using ReactJS, TailwindCSS, and Redux. The frontend is deployed with Vercel. Here are its key features:

=> Live Video Data: Utilizes Youtube's live API to display video data.
=> Search feature:
  -Provides suggestions as you type in the search bar, using debouncing.
  -Optimized to reduce unnecessary API calls by caching data.
=> Video Comments: Users can comment on videos.
=> There's a look alike live chat for each live videos in which user can send his/her chat.
=> User can play the videos and he will get suggestions of video too.
